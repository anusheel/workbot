# WorkBot public site

The marketing site for WorkBot, a second Next.js app in this workspace. Static
pages only: no database, no API routes, nothing that needs a secret. Copy is
plain and specific; claims name a capability the product has.

- `pnpm dev` serves it on http://localhost:3001; `pnpm check` runs lint, types and a build
- Shared conventions are in the root AGENTS.md
